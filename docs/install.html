Installation

Getting started with docx-a11y is simple. Choose the method that works best for you.

macOS

Download the latest .dmg from the releases page and drag to Applications.

Note: If you see a "Developer cannot be verified" warning, right-click the app and select "Open".

Windows

Download the .exe installer and follow the setup wizard.

Linux

Install via the AppImage or use the Python package manager.

CLI Installation

For power users and CI/CD pipelines, install the CLI via pip:

pip install docx-a11y
