How to use docx-a11y

Whether you are using the GUI or the CLI, the goal is the same: identify accessibility barriers and resolve them.

Your First Audit

  1. Open the App: Launch the docx-a11y GUI.
  2. Select Folder: Choose the folder containing your .docx files.
  3. Run Scan: Click "Scan for Issues". The tool will analyze headings, alt-text, table structures, and more.
  4. Review Results: Click on a document to see a detailed list of accessibility failures.

Interactive Triage

Not every "failure" is a bug. Some may be intentional or irrelevant. Use the triage system to:

  • Fix: Resolve the issue in Word and mark it as fixed.
  • Ignore: Mark the issue as a false positive or acceptable risk.
  • Export: Generate a compliance report for your organization.
