Power User Guide

For developers, DevOps engineers, and AI researchers.

CLI Reference

The CLI allows you to integrate accessibility auditing into your build pipelines.

# Scan a single file
docx-a11y scan my-doc.docx

# Scan a directory and output JSON
docx-a11y scan ./docs --format json -o report.json

CI/CD Integration

Add docx-a11y to your GitHub Actions to prevent inaccessible documents from being merged.

- name: Accessibility Audit
  run: |
    pip install docx-a11y
    docx-a11y scan ./assets/docs --fail-on-error

Agentic AI Workflows

Because docx-a11y provides machine-readable JSON output, it is ideal for LLM-driven remediation. An agent can:

  1. Run the scan via CLI.
  2. Parse the JSON report to find the exact location of a failure.
  3. Use the Python API to suggest or apply a fix to the .docx structure.
  4. Re-scan to verify the fix.
